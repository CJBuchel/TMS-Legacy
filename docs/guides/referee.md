# *FIRST* LEGO League Tournament Management System
## Referee User Guide
### Introduction
Tournament Management System (TMS) is a comprehensive, locally hosted platform designed to streamline event operations. It replaces traditional paper-based processes and rigid schedules with dynamic, real-time management tools. TMS supports digital scoring, automated timers, live schedules, and integrated scoreboards, while also enabling match and score tracking, data storage, and rollback snapshots. Together, these features provide tournament directors and volunteers with a flexible, efficient, and reliable solution for managing tournaments from start to finish

This document outlines how to use the Tournament Management System (TMS) as a referee for the *FIRST* LEGO League (FLL) regionals. 

### Home Page
As you first open TMS, you will be greeted by this home page:

![home page](<Screenshot 2025-12-01 204139.png>)

The name of the FLL regional is displayed along the top, centre of the screen.
In the top right corner, there is a sun or moon symbol to change the settings to dark mode or light mode.
Click the **Referee Scoring** button to enter the referee scoring system.
