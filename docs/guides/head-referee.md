# Guide

## Head Referee

The role of a head referee is to ensure that the robot games run on time and are reffed correctly.

The head referee page contains;
- Each individual match, along with their respective teams, tables and times
- How far ahead/behind schedule the robot games are running
- Loading, starting and rescheduling matches

### Before a Match
1. Click on the match you want to start.
    - press the blue arrow to load it
2. You will then see the match loaded on the left side with what teams.
3. When you are getting ready to start the match, click on load match and then ready match.
4. Once the match is ready to start you have 2 options on the bottom left of the screen:
    - Countdown: This will start a countdown from 5 to begin the match and start the timer
    - Start: This will immediately start the timer without any countdown

### During a Match
During the match there is not too much to do apart from watching the tables and making sure that the referees are making the right calls and nothing is being missed.
One thing that you can do during a match is use the abort button to cancel the timer.
There are very few scenarios in which you would need to abort the match:
1. you started the match too early.
2. the team wasn't ready when you started the match.
3. under any extreme circumstance when the match needs to be restarted.

### After a Match
Once the match has finished as the head referee you need to make sure that all the scores are entered into the system.
You will be able to see if a score has been submitted when the colour of the box turns from grey to green on the right hand side for that match.
Make sure that all the scores have been submitted before starting a match on the same tables.
