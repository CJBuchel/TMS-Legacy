# I am an emcee

You keep the audience informed and the energy up. TMS gives you one screen with everything you need to announce a match, and lets you start the match timer yourself if your event works that way.

!!! abstract "Your screen"
    **Match Announcer**.

## The Match Announcer screen

The screen follows the head referee. When they load a match, it appears for you.

- The **header** shows the match that is loaded, or the next match on the schedule and how long until it is due.
- The **line-up** shows each table in the match with the team's **number**, **name** and **affiliation** (their school or organisation), ready to read out.
- The **timer** shows the match clock.
- The **Start** and **Countdown** buttons start the match.

If nothing is loaded the screen says **No Matches Loaded**. If a match is loaded but the head referee has not marked it ready, the buttons show **Not Ready**.

## Announcing a match

1. Wait for the head referee to **load** the match. The line-up appears.
2. Introduce the teams, table by table.
3. Wait for the match to be marked **ready**. The start buttons become active.
4. Start the match, if that is your job at this event.

## Starting the match

| Button | What happens |
| --- | --- |
| **Countdown** | A short countdown runs on every timer, with a beep each second, then the match starts with the start sound. Use this for a "3, 2, 1, LEGO!" start. |
| **Start** | The match starts immediately with the start sound. |

Agree with the head referee before the event who presses the button. Either of you can start a match; only the head referee can stop one.

!!! info "What the audience hears"
    A sound plays at the start, another when the end-game period begins, and another at the end. They normally reach the room from a Timer screen connected to the speakers. Your Match Announcer screen plays them too, so keep your device muted unless the [screen and AV operator](av-operator.md) has asked to use it as the sound source.

## During the match

The clock on your screen is the same clock everyone sees. Call the end-game and the final seconds from it.

When the timer reaches zero the match is complete and your screen clears, ready for the next one.

## Common situations

??? question "The buttons say Not Ready"
    The head referee has not readied the match yet. Usually a table is still being reset or a team has not arrived.

??? question "The line-up is wrong"
    The schedule was changed after you last looked. Your screen is live, so read what it shows now.

??? question "I pressed Start too early"
    Tell the head referee. They can abort the timer and the match can be started again.
